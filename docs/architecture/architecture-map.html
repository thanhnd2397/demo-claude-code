Coupling to remember when adding a feature:
  • Anything that changes an Administrator's roles or status must invalidate cacheKeyAdministratorPermissions (already done in AdministratorRepositoryAdapterImpl) — otherwise authorization uses stale data for up to 15 minutes.
  • Anything that revokes access (delete/deactivate, force logout) should blacklist the current jti the same way LogoutUseCase does.
  • ValidateAccessTokenUseCase runs on every authenticated request — it is a hot path; prefer cache reads over DB there.
